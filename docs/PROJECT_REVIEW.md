# 墨研书法字库与集字字典软件项目评估

评估和完善日期：2026-09-05。登记名称暂沿用项目内“墨研书法”品牌，完整名称与版本以 `product_info.json` 为准。申请人身份、开发完成日期、首次发表情况尚待申请人确认；Git 提交日期和本次材料制作日期均不能替代开发完成日期。

## 项目定位与数据

项目为 Python / Flask / SQLite 架构的个人书法字典与集字工作区。数据库本次实测含 6,417 个不同汉字、1,313,228 条字形、3,380,973 条图像记录、5 类书体、2,230 条书家记录和 2,348 条典籍记录。这些是数据库统计，不代表内容已逐条校核或所有远程图片永久可用。

运行环境实测：Windows 11 专业版 64 位，Intel Core i9-14900K，64 GB 内存；Python 3.13.14，Flask 2.3.3，Werkzeug 3.1.6，Pillow 12.1.0，requests 2.31.0，python-dotenv 1.0.0，Chrome。requirements.txt 中 Pillow 固定为 11.3.0，与本机已有环境存在差异；本轮验收针对上述实际环境，不宣称已验证所有部署系统。

## 正式版本范围

首页、书法字典、字形详情、图版放大、收藏、集字创作、逐字选图、缺字提示、横排左起、横排右起、竖排左起、竖排右起、作品保存与继续编辑、PNG 导出、浏览器草稿、作品列表、偏好设置、工作区备份恢复、纠错记录和使用指南构成 V1.0 的使用范围。

本版本按汉字精确检索，不提供通用汉语释义、拼音和笔顺，也未加入自动繁简转换。仓库内的 CalliReader / InternVL 模型、OCR 实验页面、核查脚本和旧静态脚本属于维护或历史内容，不作为正式用户功能在说明书中宣传。没有进行公网部署、应用商店发布、账号体系或多人权限管理。

## 数据与技术边界

主字库只读，新增数据进入独立工作库。浏览器偏好和草稿保存在当前浏览器；服务端作品和收藏由同一实例共享。默认绑定 127.0.0.1。新增写接口检查 Origin，拒绝已声明的跨站来源；这不是完整登录鉴权。若未来作为公网多人服务，应另行设计身份认证、用户隔离、访问控制和速率限制。

图版按数据库图片编号获取，支持配置本地优先。图版读取失败不会被当作成功导出。导出允许 1 至 200 个字、1 至 20 个字一行或列、80 至 400 px 字格、0 至 60 px 间隔，并限制为 36 百万总像素。透明画布保留原始字图底色。原图清晰度不会因较大输出尺寸而自动提高。

备份包含作品、收藏和纠错，不含原始字库、图版、浏览器偏好与草稿。恢复保留现有数据，并对完全相同的作品内容和已有收藏去重；同名但内容不同的作品作为新增保存。纠错状态仅用于人工核查记录，不会修改字库，也不会发送给外部机构。

## 验收结论

新增单元与接口测试 13 项通过，原有测试 6 项通过。浏览器验收通过 9 项工作流检查以及首页、字典、集字和设置的 4 项移动宽度检查；页面 JavaScript 异常为 0。验收使用独立演示工作库和原有真实字图库；像素方向测试使用测试程序构造的彩色矩形，和材料中的真实运行截图明确分离。

测试文件：`tests/test_product.py`、`tests/run_tests.py`、`tools/preview_qa.cjs`。原始截图和浏览器验收记录保存在 `tmp/qa/`；交付材料内附正式选用截图与验收摘要。
